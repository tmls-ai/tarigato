# Tarigato mark

An original vermilion cat/fox symbol made from interlocking folded forms. It represents the builder and challenger roles. The website pairs the symbol with a simple lowercase sans-serif wordmark. No Japanese characters are used.

Asset: `dist/assets/tarigato-mark.png` — 1254 × 1254 RGBA PNG with a transparent background.

Generated with the built-in image generation tool. The result was visually inspected at large and small sizes. This is a raster asset, not a vector master.

## Final generation prompt

Use case: logo-brand
Asset type: original standalone logo symbol for Tarigato, a polished developer tool website. A clean lowercase sans-serif wordmark will be added separately; generate the symbol only.
Primary request: A compact origami-like alert cat / fox mask formed from two interlocking folded angular strokes, quietly representing a builder agent and a challenger agent.
Style: modern Japanese graphic-design restraint, clever negative space, extremely simple bold flat forms, a memorable strong silhouette readable at 24px, balanced slight asymmetry. Original design, refined and confident.
Color palette: one solid vermilion red-orange ink, #e54835.
Composition: one centered symbol on a square transparent canvas, modest 10% margins. Crisp vector-like raster edges.
Constraints: genuinely transparent background; no lettering, words, fake kanji, watermark, badge circle, extra motifs, gradients, texture, 3D, shadows, anime, samurai or other cultural cliches. No mockup or presentation board. Only the standalone symbol.

## Type

Manrope is used for interface text. IBM Plex Mono is used for code and the interactive expiry expression. The two fonts are self-hosted under the SIL Open Font License, with licenses in `dist/assets/fonts/`. The Latin subset covers English and German. Japanese and Chinese use native sans-serif fallbacks.

## Interactive identity

The homepage enlarges the session-expiry expression into an interactive proof sheet. Visitors can move the expiry value across the exact boundary and compare the candidate with the stated requirement. Showing the repair removes the equality character. This example is evaluated in JavaScript, independently of the complete browser workflow simulation.
